# 中文写作指南

个人博客「读书与编程」的写作参考。基于本站历史文章的常见错误整理，分四个层次：**写对 → 写明白 → 写少 → 写好**。

---

## 一、写对（正确性）

### 1. 同音字是最大敌人（拼音输入的坑）

错别字 90% 来自同音字。对策：

- 拿不准的字就查，别凭手感。人名、机构名必须查证（单伟**建**、对外经济贸易大学）
- 重点盯常错的几组（本站历史错误）：

| ❌ 错误 | ✅ 正确 | 说明 |
|---|---|---|
| 觉的 | 觉得 | 「觉得」是固定词 |
| 请示 | 请求 | 「请示」是下级向上级汇报；写系统/代码场景几乎都是「请求」(request) |
| 纪录（动词） | 记录 | 动词用「记录」；「纪录」只做名词（打破纪录） |
| 一分种 | 一分钟 | 时间单位是「分钟」 |
| 只会...相关 | 只和...相关 | 「相关」和「会」不搭 |
| 不重要（动词位） | 不重视 | 「重要」是形容词，这里要动词「重视」 |
| 省下来 | 生下来 | 「生」=出生 |
| 单伟健 | 单伟建 | 人名，同音字最坑 |

### 2. 的 / 地 / 得

```
的 + 名词    美丽的花、我的书
地 + 动词    慢慢地走、100%地投入
得 + 补语    跑得快、觉得很不错
```

口诀：**的定语、地状语、得补语**。

### 3. 量词要配对

| 名词 | 量词 |
|---|---|
| 图片、纸、桌子 | 张 |
| 书、文章 | 本、篇 |
| 数据集、系统、项目 | 个 |
| 牛、马 | 头、匹 |

### 4. 标点（中文全角）

- 疑问句 → ？，不用句号
- 中文引号 →「」""，不用英文直引号
- 列举 → 顿号「、」
- 中英文之间留空格，但标点前不留空格：`ImageNet ，` ✗ → `ImageNet，` ✓

### 5. 句子完整

每个句子要有**主语 + 谓语**。写完问自己：**谁**在**干什么**？

> ❌ 之后和美帝读书，与同是移民的老师认识等。
> ✅ 之后在美国读书，与同是移民的老师认识等。

## 二、写明白（清晰性）

### 1. 一句一意，长句拆短

一句话只讲一件事；超过 40 字就考虑拆句。

> ❌ 之后，由李鸿章和儿子作为全权大臣到马关议和。谈判过程中，李鸿章被刺杀，子弹射入面部。中方没有借助此事件，增加谈判筹码，是一大失误。另外不重要电报加密，导致自己的筹码被别人看得清清楚楚。

> ✅ 之后由李鸿章父子作为全权大臣赴马关议和。谈判期间李鸿章遇刺，子弹射入面部。中方未借此事件增加谈判筹码，是一大失误；又不重视电报加密，筹码被对方看得清清楚楚。

### 2. 指代要清楚

「它/他/这/那」尽量指最近提到的名词。主语不明时要补上：

> ❌ 比赛直到第三届遇到 AlexNet，开启了深度学习时代。
> ✅ 比赛进行到第三届，AlexNet 的出现开启了深度学习时代。

### 3. 逻辑连接词用准

| 关系 | 连接词 |
|---|---|
| 因果 | 因为…所以…、因此、由于 |
| 转折 | 但是、然而、却、不过 |
| 让步 | 虽然…但是…、尽管 |
| 递进 | 而且、甚至、不仅…还 |

### 4. 术语前后一致

同一个概念全篇用同一个词（如「批量化写入」与「批量写入」选一个，别混）。

## 三、写少（简洁性）

中文写作最大的加分项是**删**：

- **的**：多个「的」连用时可删——`我们日常接触的历史教科书的叙述组织方式` 保留一两个就够
- **进行**：`进行优化` → `优化`；`进行讨论` → `讨论`
- **一个**：`一个多达几万类别` → `多达几万类别`
- **了**：句尾「了」别连用
- **其实/确实/非常**：口语填充词，能删就删

规则：写完删掉 20% 的字数，通常更清晰。

## 四、写好（风格与节奏）

### 1. 警惕翻译腔

- 滥用被动：「被评价为」「被认为是」用多了很翻译腔
- 滥用名词化：`对该问题的解决` → `解决这个问题`
- 「进行」+动词：见上

中文多用**主动、短句、具体动词**。

### 2. 具体 > 抽象

> ❌ 这本书还不错，推荐读一读。
> ✅ 作者介绍了自己从华南理工毕业后，到广西从小工干到厂长的故事。

给细节：数字、场景、人名，比形容词可信得多。

### 3. 一段一意 + 小标题

每段开头一句是主题句，段落之间用空行。技术文章/长文用小标题分节。

### 4. 口语化可以，但要控制

博客适合口语化（生动），但口语词（然后、就是说、其实）连用会显啰嗦。**生动 ≠ 啰嗦**。

## 五、写作流程

1. **打草稿**：先写出来，别边写边改
2. **冷置**：写完放半小时再回来看，能发现一半问题
3. **朗读**：读出声，读着别扭的地方就是要改的地方
4. **查证**：人名、术语、数字必须查
5. **对照清单**：过一遍 CLAUDE.md 的错别字清单 + 上面四层检查
